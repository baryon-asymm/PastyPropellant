# BOOT.md — ParametricCombustionModel.ReportMaking

## Purpose

Сборка PDF-отчёта по результату оптимизации: разделы превращают результат в
операции печати, сборщик исполняет их через внешний адаптер PDF. Библиотека;
файл она пишет в рабочий каталог процесса.

## Invariants

- Разделение «раздел считает — сборщик печатает» несущее. Раздел — чистое
  преобразование, поэтому тестируется без PDF-библиотеки; порядок разделов,
  имена картинок и вызовы генератора живут в одном месте, в
  [ReportMakers](./ReportMakers/API.md).
- Отчёт — вывод, а не модель: он не считает физику и не имеет права
  пересчитывать результат. Всё, что он печатает, приходит готовым.
- Отчёт не знает консольный хост. Конфигурация запуска приходит уже
  отформатированным текстом (`RunConfigurationSection`), иначе библиотека
  ссылалась бы на приложение.
- Числа, показанные в отчёте, и числа, годные для воспроизведения, — разные
  вещи. Первые округлены для чтения; воспроизводит только блок вектора в
  полной точности и вложенный `best_vector.txt`.
- Несошедшийся расчёт печатается словами, а не числом: контексты
  переиспользуются между вычислениями, поэтому поле скорости горения может
  держать чужое значение, и единственный достоверный признак — флаг
  сходимости.
- Локализация есть, но не задействована: сателлитные сборки `en-US` и
  `fr-FR` собираются, культуру никто не выставляет, имя отчёта зашито как
  `propellants.group_optimization.report.en.pdf`.

## Dependencies

- [Optimization](../ParametricCombustionModel.Optimization/API.md) — результат
  оптимизации, настройки ДЭ, контексты задачи;
- [Core](../ParametricCombustionModel.Core/API.md) — описание топлива;
- [Telemetry](../ParametricCombustionModel.Telemetry/API.md) — измерения
  производительности для последнего раздела.

Вне дерева: `PDFsharp.Api` из `externals/` (адаптер генератора) и `PdfSharp`
(ориентация страницы, выравнивание). Внешний `PastyPropellant.Core` даёт
единый источник имён композиций.

## Constraints

Унаследованы от [корня дерева](../../BOOT.md). Дополнительно:

- Имена файлов картинок — контракт с [PlotRenderer](../ParametricCombustionModel.PlotRenderer/API.md)
  и с Python-помощниками хоста; пути относительны рабочему каталогу процесса.
- Форматирование чисел — `CultureInfo.InvariantCulture`.

## Acceptance criteria

- [x] Разбивка ошибки сходится с целевой функцией; несошедшийся расчёт даёт
      маркер; ген у границы помечен; блок композиции подписан своей
      композицией (2026-09-05, узел
      [ReportMaking.Tests](../../tests/ParametricCombustionModel.ReportMaking.Tests/BOOT.md)).
- [ ] `IReportMaker.MakeReport()` обещает строку, а `GroupPdfReportMaker`
      возвращает пустую — расхождение «как есть / как должно быть».
- [ ] Порядок разделов и имена файлов картинок не покрыты ни одним тестом.
- [ ] Малые потоки печатаются в кВт/м² под подписью Вт/м².

## Taboos

- Не считать в отчёте ничего, что должен был посчитать решатель.
- Не давать разделу знать о PDF, а сборщику — о конфигурации запуска.
- Не печатать скорость горения, не спросив флаг сходимости.
