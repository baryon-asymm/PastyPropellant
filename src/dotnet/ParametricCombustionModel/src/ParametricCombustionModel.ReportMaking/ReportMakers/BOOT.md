# BOOT.md — ReportMakers

## Purpose

Единственный сборщик отчёта: складывает разделы в фиксированный порядок,
исполняет их операции печати через адаптер PDF и генерирует файл.

## Invariants

- Здесь и только здесь живут порядок разделов, имена файлов картинок и вызовы
  генератора. Разделы об этом не знают — см. [Reports/Pdf](../Reports/Pdf/API.md).
- Сборщик и есть посетитель: `GroupPdfReportMaker` реализует
  `IPdfOperationVisitor`, а `operation.Accept(this)` направляет каждую
  операцию в её `Visit`. Добавление операции печати требует нового `Visit`
  здесь — компилятор это потребует, потому что интерфейс посетителя закрытый.
- Порядок разделов фиксирован: шапка → конфигурация запуска (если непустая) →
  штрафы → параметрические ограничения → настройки ДЭ → параметры решателя →
  вектор воспроизведения → целевая функция → разбивка ошибки → подгонка
  Вьеля → структура пламени → контекст задачи → таблицы по давлениям →
  графики скорости горения → топливо → графики Python → графики каркасного
  слоя → производительность → подвал → вложение `best_vector.txt`.
- Групповой результат склеивается в одиночный (`ToOptimizationResult()`)
  ровно для тех разделов, что наследуют `BaseReport`; разделы, чьи числа
  обязаны сходиться с целевой функцией, получают групповой результат
  напрямую.
- Необязательное деградирует, а не ломает отчёт: лог-лог график, четыре
  графика каркасного слоя и вложение `best_vector.txt` защищены проверкой
  наличия файла. Шесть графиков Python и основной график скорости горения —
  нет.
- Пути картинок относительны рабочему каталогу процесса, не каталогу
  сборки: отчёт собирается там же, где отработали Python-помощники.
- Знак минуса `U+207B` заменяется на `U+00AF` при печати текста: шрифт PDF
  не имеет надстрочного минуса.
- Провал генерации — `InvalidOperationException`, а не тихий возврат.

## Constraints

- Библиотека отчётов не знает консольный хост: конфигурация запуска приходит
  уже отформатированным текстом.
- Формат чисел — `CultureInfo.InvariantCulture`.

## Acceptance criteria

- [x] Сборка проекта: интерфейс посетителя закрыт, каждая операция имеет
      `Visit` (2026-09-05).
- [ ] `MakeReport()` возвращает `string.Empty` — сигнатура обещает путь к
      отчёту, а возвращается ничто. Расхождение «как есть / как должно быть».
- [ ] Порядок разделов и имена файлов ничем не покрыты: тестов на сборщик
      нет, только на разделы.

## Taboos

- Не переносить порядок разделов или имена файлов в сами разделы.
- Не снимать защиту `File.Exists` с необязательных вложений.
- Не давать сборщику знать о типе конфигурации запуска.
