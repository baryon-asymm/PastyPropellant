# BOOT.md — Interfaces

## Purpose

Четыре контракта отчётности: операция вывода в PDF и её посетитель, автор
отчёта и преобразователь раздела в свой выход.

## Invariants

- Отчёт строится **посетителем над очередью операций**, а не прямыми вызовами
  генератора PDF. Благодаря этому разделы отчёта не знают, чем именно рисуется
  документ, и их можно проверять тестом, читая очередь операций вместо
  сравнения PDF.
- `ITransformable<out T>` ковариантен и намеренно не привязан к очереди
  операций: раздел таблиц отдаёт коллекцию таблиц, а не операции текста.
- `IReportMaker.MakeReport` возвращает `string`. ⚠ Единственная реализация
  возвращает **пустую строку**, а документ пишет по пути, заданному
  генератору. Возвращаемое значение сейчас ничего не значит.

## Dependencies

- [PdfOperations](../PdfOperations/API.md) — три конкретные операции в
  сигнатурах посетителя.
