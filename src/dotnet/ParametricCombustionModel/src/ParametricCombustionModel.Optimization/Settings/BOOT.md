# BOOT.md — Settings

## Purpose

Настройки поиска: выбранный вариант дифференциальной эволюции с его
параметрами, размер популяции, границы, условие остановки, число воркеров,
зерно ГСЧ и настройки полировки Нелдера — Мида.

## Invariants

- Настройки собираются **построителем и проверяются при сборке**, а не при
  использовании: отсутствие обязательного поля, границы разной длины,
  перевёрнутая граница, `F` вне `[0, 2]`, `CR` вне `[0, 1]`, неположительная
  популяция или число воркеров — исключение в `Build()`.
- Готовый объект — `record` с `init`-свойствами: после сборки он неизменяем и
  безопасен для чтения из всех воркеров.
- **Проверяются все ветви, а не только выбранная.** L-SHADE требует бюджета
  вычислений, и его отсутствие — ошибка сборки, даже если стратегия сейчас
  другая. Сломанная настройка не может дремать до момента переключения.
- Стратегия по умолчанию — `Shade`. Значения по умолчанию для адаптивных
  вариантов повторяют библиотеку (Tanabe & Fukunaga 2013): `pBestRate` 0.1,
  `archiveSizeRate` 1.0, `memorySize` 100, скорость адаптации JADE 0.1.
- Зерно необязательно (`null` — историческое поведение, каждый запуск свой).
  Засеянный запуск воспроизводим **только при том же числе воркеров**, поэтому
  зерно и число воркеров обязаны записываться в отчёт вместе.
- ⚠ `NelderMeadRefinementSettings.Validate` **отвергает `MemeticInLoop`** — не
  потому что режим бессмыслен, а потому что пакет-адаптер двоично несовместим
  с ДЭ 5.x и упал бы на N-м поколении, часами позже старта, с потерянным
  состоянием поиска. Удаление одного этого `throw` и есть вся работа по
  включению режима, когда адаптер выйдет.
- Включённая полировка без выбранной стадии (ни мемётической, ни финальной) —
  тоже ошибка: молчаливо ничего не делать настройкам не разрешено.

## Dependencies

None. Узел зависит только от внешних для дерева контрактов библиотеки
`DotNetDifferentialEvolution` (стратегия остановки, обработчик обновления
популяции).

## Constraints

Унаследованы от [Optimization](../BOOT.md). Дополнительно: всё, что попадает
сюда, обязано попадать и в отчёт о запуске — настройка, которой нет в отчёте,
делает результат невоспроизводимым.

## Acceptance criteria

- [x] Засеянный запуск воспроизводим при том же числе воркеров и не переносим
      между разными (2026-09-05,
      `DifferentialEvolutionDeterminismContractTests`, узел
      [Optimization.Tests](../../../tests/ParametricCombustionModel.Optimization.Tests/BOOT.md)).
- [x] Устаревший конструктор с провайдером случайных чисел больше не задаёт
      зерно (2026-09-05,
      `DifferentialEvolutionDeterminismContractTests.TheLegacyRandomProviderConstructor_IsObsoleteAndNoLongerSeedsARun`).
- [ ] Проверки построителя собственными тестами не покрыты.

## Taboos

- Не ослаблять проверку неиспользуемой ветви: смысл в том, что сломанная
  настройка падает сразу.
- Не включать `MemeticInLoop`, пока адаптер собран против ДЭ 4.0.0.
