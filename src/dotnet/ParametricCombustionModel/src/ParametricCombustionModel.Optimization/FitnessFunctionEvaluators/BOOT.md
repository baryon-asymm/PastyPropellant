# BOOT.md — FitnessFunctionEvaluators

## Purpose

Целевая функция: насколько посчитанные скорости горения отличаются от
измеренных, и добавка штрафов за нарушенные ограничения. Уровень существует,
чтобы определение «насколько хорошо» было записано ровно один раз.

## Invariants

- Мера — **средняя по топливам среднеквадратичная относительная невязка**: по
  каждому топливу берётся корень из среднего квадрата относительной ошибки по
  всем давлениям, затем эти значения усредняются по топливам. Относительная,
  а не абсолютная: скорости отличаются на порядок между давлениями.
- Делится на **число давлений**, а не на число точек, где ошибка посчиталась.
  Точка, не давшая ошибки, не улучшает результат.
- **Одна несошедшаяся точка обнуляет всё**: обнаружив
  `BurnRateIsFound == false`, оценщик немедленно возвращает `double.MaxValue`.
  Никакого частичного результата не бывает.
- Штрафной оценщик — наследник обычного, и он **сначала сбрасывает** накопленные
  штрафы, потом зовёт базовый, и **выходит, не считая штрафов**, если целевая
  функция уже `double.MaxValue`. ⚠ Отсюда та же ловушка отчётности: нулевой
  штраф у несошедшегося решения означает «не считался».
- Штрафы накапливаются по всем топливам и давлениям для каждого оценщика
  отдельно (`EvaluatedPenalties`) и суммарно (`TotalEvaluatedPenalty`), чтобы
  отчёт мог показать вклад каждого ограничения.
- Оценщик **не имеет состояния**: всё пишется в переданную задачу, поэтому
  один экземпляр обслуживает все воркеры.

Унаследованы от [Optimization](../BOOT.md). Дополнительно: это самый горячий

не должно.

## Acceptance criteria

- [x] Среднеквадратичная невязка по топливу равна корню из среднего квадрата
      относительных ошибок, делится на число давлений и равна нулю при точном
      совпадении (2026-09-05, `BurnRateErrorReportTests`, узел
      [ReportMaking.Tests](../../../tests/ParametricCombustionModel.ReportMaking.Tests/BOOT.md)).
- [x] Невязка подавляется целиком, если хотя бы одна точка не сошлась
      (2026-09-05, `BurnRateErrorReportTests.PerFuelRms_IsSuppressedEntirelyWhenAnyPointDidNotConverge`).
- [ ] Собственных тестов у узла нет: определение целевой функции проверяется
      косвенно, через отчёт, который его пересчитывает.

## Taboos

- Не возвращать частичную целевую функцию при несошедшейся точке.
- Не заводить состояние: оценщик разделяется между воркерами.
