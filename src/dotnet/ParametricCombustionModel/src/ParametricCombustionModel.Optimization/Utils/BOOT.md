# BOOT.md — Utils

## Purpose

Единственный способ записать вектор параметров текстом. Уровень существует
потому, что вектор пишется в двух местах — в файл рядом с запуском и в блок
воспроизведения внутри PDF, — и эти два представления обязаны совпадать.

## Invariants

- Ген пишется в формате **`"R"` с инвариантной культурой**. ⚠ Это несущее
  требование, а не аккуратность: округлённый до отображаемых знаков вектор
  **не воспроизводит** свою целевую функцию, потому что замыкание по
  радиационной температуре усиливает ошибку четвёртого знака.
- По одному гену на строку: так представление устойчиво к переносу строк при
  извлечении текста из PDF.
- Контрольная сумма — SHA-256 в нижнем регистре по канонической записи с
  переводами строк. Она устойчива к циклу запись → разбор → повторная запись
  (`double → "R" → double → "R"` идемпотентно), поэтому читатель может
  пересчитать её по разобранным значениям и поймать значение, испорченное при
  копировании, даже если число значений сохранилось.
- Класс статический и без состояния.

## Acceptance criteria

- [x] Формат используется обоими потребителями из одного места (2026-09-05,
      по коду: файл вектора пишет хост, блок воспроизведения — узел
      [Reports/Pdf](../../ParametricCombustionModel.ReportMaking/Reports/Pdf/API.md)).
- [ ] Идемпотентность цикла «запись → разбор → запись» тестом не закреплена ни
      в одном узле дерева.

## Taboos

- Не форматировать вектор нигде, кроме этого узла.
- Не переходить на культурозависимое форматирование или на фиксированное число
  знаков.
