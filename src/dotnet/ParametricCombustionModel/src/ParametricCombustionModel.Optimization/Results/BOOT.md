# BOOT.md — Results

## Purpose

Результат группового поиска: три посчитанных размерных контекста, границы,
найденный 32-вектор и разложение целевой функции и штрафов по композициям.
Плюс переходник к одиночному результату, которым пользуется отчётность.

## Invariants

- Контекстов ровно три, вектор ровно 32 элемента, `null` вместо границ —
  исключение. Конструктор проверяет всё это и бросает, а не подгоняет.
- Индексация всюду в **сырой раскладке вектора**: 0 — `Bas_2 + Bas_3 + Bas_4`,
  1 — `Bas_1`, 2 — `Bas_0`. Любой отчёт обязан ходить по композициям в этом же
  порядке.
- Агрегаты выводятся в конструкторе из контекстов и не задаются снаружи:
  целевая функция — среднее трёх, штраф — сумма трёх. Разойтись со своими
  слагаемыми они не могут.
- Переходник склеивает три матрицы контекстов в одну **5 × число давлений**
  (3 + 1 + 1 топлива) в том же порядке композиций и требует одинакового числа
  давлений во всех трёх, иначе бросает.
- ⚠ Переходник отдаёт **пустые границы**: для склеенного контекста они не
  осмысленны. Потребитель, которому нужны границы, обязан брать их из
  группового результата, а не из переходного.
