# BOOT.md — Common

## Purpose

Мировые физические постоянные, не зависящие ни от топлива, ни от режима:
универсальная газовая постоянная и постоянная Стефана — Больцмана. Уровень
существует, чтобы такие числа были написаны в дереве ровно один раз.

## Invariants

- Здесь лежат только **справочные постоянные СИ**, значения которых не
  обсуждаются и не настраиваются. Всё, что можно выбрать для кампании расчётов
  (температура плавления металла, вилка температуры поверхности, замыкание
  поверхностной доли каркаса), — это конфигурация и живёт в
  [KnownParams](../Models/KnownParams/API.md), а не здесь.
- Значения даны с полной точностью определения СИ и не округляются:
  `8.314_462_618_153_24` Дж/(моль·К) и `5.670_374_419_184_43e-8` Вт/(м²·К⁴).
- Класс статический, полей нет, состояния нет — узел безопасен для любого числа
  параллельных воркеров по построению.

## Acceptance criteria

- [x] Постоянные совпадают с определениями СИ (2026-09-05, сверено по значениям
      в коде).
- [ ] Машинной проверки, что здесь не появилось настраиваемой величины, нет:
      это держится табу ниже.

## Taboos

- Не добавлять сюда ни одной величины, которую кто-то может захотеть изменить
  для расчёта. Такая величина обязана попасть в отчёт о запуске, а `const` в
  исходнике в отчёт не попадает — именно этот урок и разделил узлы.
