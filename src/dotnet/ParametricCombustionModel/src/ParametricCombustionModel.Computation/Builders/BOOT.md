# BOOT.md — Builders

## Purpose

Сборка матрицы контекстов «топливо × давление» из списка топлив и постоянных
запуска. Уровень существует, чтобы весь перевод данных в контекст расчёта
происходил в одном месте и одинаково для двух ярусов.

## Invariants

- **Матрица `[топливо, давление]`**, где давления берутся из
  `PressureFrames` **первого** топлива списка. Отсюда следует требование ко
  входным данным: у всех топлив набор давлений обязан совпадать, иначе часть
  контекстов соберётся не с тем кадром.
- `BuildMatrix` бросает `InvalidOperationException`, если давления не заданы,
  и не строит пустую матрицу.
- `FromPropellants` с `null` вместо постоянных берёт `ModelConstants.Default`,
  то есть исторические значения. Отсутствие конфигурации — не отдельная ветка
  поведения, а тот же объект без переопределений.
- Поверхностная доля каркаса берётся **только** через
  `GetSkeletonCoverage(pressure, ModelConstants.SkeletonSurfaceFraction)`, то
  есть выбранное замыкание доходит до обоих ярусов из одной точки.
- Вилка температуры поверхности проставляется в каждый контекст из
  `ModelConstants`, а не читается решателем из постоянных.
- ⚠ `CondensedThermalConductivity = 150.0` Вт/(м·К) **вписана в код** обоих
  сборщиков. Это материальное свойство, но живёт оно не в данных и не в
  конфигурации, поэтому в отчёт о запуске не попадает. Расхождение
  зафиксировано в [корневом BOOT.md](../../../BOOT.md).
- Пара сборщиков обязана оставаться зеркальной: одна и та же матрица в двух
  ярусах, различие только в типах.

## Dependencies

- [Models](../../ParametricCombustionModel.Core/Models/API.md) — `Propellant`
  и `PressureFrame` как вход;
- [Extensions](../Extensions/API.md) — объёмные доли, диаметр окислителя,
  температура кипения металла, поверхностная доля каркаса;
- [KnownParams](../Models/KnownParams/API.md) — `ModelConstants` и все входные
  структуры контекста;
- [ComputedParams](../Models/ComputedParams/API.md) — поля результата,
  инициализируемые в контексте;
- [ProblemContexts](../Models/ProblemContexts/API.md) — собираемый тип.

## Constraints

Унаследованы от [Computation](../BOOT.md). Дополнительно: сборщик вызывается
до начала поиска и **по одному разу на воркер** — матрица мутируется в ходе
решения, поэтому каждый воркер обязан получить свою свежую копию.

## Acceptance criteria

- [x] Настроенные постоянные (вилка, коэффициент контакта, замыкание) доходят
      до собранных контекстов обоих ярусов (2026-09-05,
      `SurfaceTemperatureBracketTests.AConfiguredBracketReachesBothTiers`,
      `SkeletonSurfaceFractionTests.BothContextTiersUseTheConfiguredClosure`,
      `SkeletonContactFactorTests`, узел
      [Computation.Tests](../../../tests/ParametricCombustionModel.Computation.Tests/BOOT.md)).
- [ ] Требование «у всех топлив одинаковые давления» не проверяется: сборщик
      молча берёт кадры первого топлива.
- [ ] Зеркальность двух сборщиков машиной не проверяется.

## Taboos
 
- Не переиспользовать одну матрицу между воркерами.
- Не читать постоянные модели напрямую из `PropellantExtensions`: только через
  `ModelConstants`, иначе настроенный запуск посчитает при значении по
  умолчанию.
