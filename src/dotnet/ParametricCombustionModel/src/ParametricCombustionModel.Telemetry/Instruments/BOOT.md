# BOOT.md — Instruments

## Purpose

Измерительные приборы телеметрии: описание прибора, два вида измерителя
интервала выполнения (однократный и накапливающий статистику) и точка съёма
показаний сборщика мусора.

## Invariants

- Прибор описывает себя сам: имя, описание, единица, путь. Путь — иерархия
  для отчёта, а не файл.
- Кадр измеряется через `using`: `StartFrame()` возвращает сам измеритель,
  `Dispose()` вызывает `EndFrame()`. Забыть закрытие кадра поэтому нельзя.
- Накапливающий измеритель считает среднее и дисперсию **потоковым**
  алгоритмом Уэлфорда, за один проход и без хранения выборки: измеритель
  живёт весь прогон и получает миллионы кадров, а список кадров стоил бы
  памяти на горячем пути.
- ⚠ Измеритель **не потокобезопасен**: `CallsCount`, среднее и дисперсия
  обновляются без синхронизации. Это работает только потому, что измеритель
  заводится **по одному на воркер** — общий на несколько потоков даёт
  испорченную статистику молча.
- Пустой накапливающий измеритель отдаёт `MinExecutionTime = double.MaxValue`
  и `MaxExecutionTime = double.MinValue`: инициализация нарочно такая, чтобы
  первый же кадр их перекрыл, — но читателю показаний надо смотреть на
  `CallsCount`.
- Однократный измеритель заводит секундомер уже в конструкторе и запоминает
  `StartTime`: он меряет прогон целиком, поэтому «создан» и есть «начат».
- Время везде в миллисекундах.
- Съём показаний сборщика мусора не форсирует сборку: `GC.GetTotalMemory(false)`.

## Dependencies

None

## Constraints

- `System.Diagnostics.Stopwatch` как источник времени; `DateTime.Now` — только
  для отметок начала и конца прогона в отчёте.

## Acceptance criteria

- [x] `ExecutionFrameMeasurerTest` — кадр меряется и статистика набирается
      (узел [Telemetry.Tests](../../../tests/ParametricCombustionModel.Telemetry.Tests/BOOT.md)).
- [ ] Непотокобезопасность измерителя ничем не проверяется — держится
      соглашением «один воркер — один измеритель».

## Taboos

- Не делить один накапливающий измеритель между потоками.
- Не хранить выборку кадров ради статистики.
- Не форсировать сборку мусора ради показаний.
