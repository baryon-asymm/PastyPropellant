# BOOT.md — Extensions

## Purpose

Одно расширение потока: перевести позицию в начало. Существует потому, что
экспорт изображения пишет в поток, а вызывающая сторона тут же читает его с
начала, и забытый `Position = 0` даёт пустое изображение без ошибки.

## Invariants

- Узел заведомо тривиален и обязан таким остаться: он не место для утилит
  общего назначения.

## Dependencies

None.

## Constraints

Унаследованы от [PlotRenderer](../BOOT.md).

- [x] Поток, отданный наружу, читается с начала (2026-09-05, косвенно

      [PlotRenderer.Tests](../../../tests/ParametricCombustionModel.PlotRenderer.Tests/BOOT.md):
