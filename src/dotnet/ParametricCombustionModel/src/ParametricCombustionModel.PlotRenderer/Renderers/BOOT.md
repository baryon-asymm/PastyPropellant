# BOOT.md — Renderers

## Purpose

Два графика скорости горения по групповому результату: в линейных осях и в
двойных логарифмических. Плюс общая часть — построение модели графика и её
вывод в файл, байты или поток.

## Invariants

- ⚠ **Ошибку рисования приходится доставать вручную.** OxyPlot глотает
  исключение рендера, подставляет панель ошибки и кладёт настоящее исключение
  в `PlotModel.GetLastPlotException()`. Экспорт обязан его перебросить, иначе
  сломанный график молча превращается в картинку с текстом ошибки. Это
  наблюдённое поведение библиотеки, а не предположение.
- ⚠ Два топлива, `Bas_21` и `Bas_22`, **исключены из графиков** по имени. Они
  подварианты `Bas_2` и рисовались бы поверх него. Исключение сделано так,
  что пропущенное топливо **не занимает цветовой слот**: иначе цвета
  разъезжались бы относительно легенды.
- Цвет и маркер выдаются **синхронно**, из двух параллельных статических
  массивов, по одному индексу. Топливо без точек серии не порождает.
- Логарифмический график существует не для красоты: степенной закон Вьеля в
  двойных логарифмических осях — прямая, поэтому расхождение по показателю
  давления видно наклоном.
- Рисовальщики пишут файлы в **рабочий каталог процесса** с фиксированными
  именами (`group_burning_rate_plot.jpg`,
  `group_burning_rate_loglog_plot.jpg`), которые ожидает отчёт.

## Acceptance criteria

- [x] Экспорт переносит наружу **первичное** исключение рисования, а не
      вторичную ошибку панели ошибок (2026-09-05,
      `BasePlotRendererErrorSurfacingTest`).
- [x] Пустая модель и модель с одной серией экспортируются в JPEG без сбоя
      загрузки сборок (2026-09-05, `JpegExporterDiagnosticTest`).
- [x] Подварианты `Bas_2` отбрасываются независимо от их места в матрице, не
      занимают цветовой слот, сам `Bas_2` остаётся, цвет и маркер идут в
      ногу, и на каждой кривой по точке на давление (2026-09-05,
      `GroupSeriesCollectionTests`).

Все тесты — в узле
[PlotRenderer.Tests](../../../tests/ParametricCombustionModel.PlotRenderer.Tests/BOOT.md).
⚠ Этот тестовый проект **не входит в решение**, поэтому обычный прогон тестов
его не запускает.

## Taboos

- Не глотать исключение рисования: без переброса сломанный график выглядит
  как успешный.
- Не давать пропущенному топливу занимать цветовой слот.
- Не переименовывать выходные файлы в одиночку.
