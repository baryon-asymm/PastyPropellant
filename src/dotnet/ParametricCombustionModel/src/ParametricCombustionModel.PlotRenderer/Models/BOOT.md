# BOOT.md — Models

## Purpose

Настройки графика и одна серия данных для группового графика. Уровень
существует, чтобы вид изображения задавался объектом, а не набором
аргументов.

## Invariants

- У всех настроек есть значения по умолчанию, и они рассчитаны на **печать**,
  а не на экран: 8000 × 8000 точек, 600 dpi, качество 100. Значение по
  умолчанию здесь — часть контракта: график, вставляемый в PDF, обязан быть
  читаемым в бумажном отчёте.
- Пределы осей по умолчанию — `double.NaN`, что означает «автоматически».
  Потребитель обязан различать NaN и заданное значение, а не сравнивать с
  нулём.
- `GroupPlotSeriesData` — запись, несущая **и посчитанные, и измеренные**
  точки одной кривой вместе с её цветом и маркером. Одно топливо — одна
  запись; цвет и маркер выбраны заранее, а не в момент рисования.
- Запись несёт саму `Propellant`, потому что рисовальщику нужны её
  доверительные интервалы.

## Dependencies

- [Models](../../ParametricCombustionModel.Core/Models/API.md) — `Propellant`
  внутри серии данных.

## Constraints

Унаследованы от [PlotRenderer](../BOOT.md). Дополнительно: одна серия — одно
топливо. Раскладка «по одному графику на топливо» в этом дереве запрещена:
число топлив меняется, и сетка подграфиков рассыпается.

## Acceptance criteria

- [x] Цвет и маркер выдаются согласованно и одному топливу соответствует одна
      серия (2026-09-05, `GroupSeriesCollectionTests`, узел
      [PlotRenderer.Tests](../../../tests/ParametricCombustionModel.PlotRenderer.Tests/BOOT.md)).
- [ ] Значения по умолчанию (размер, dpi) тестом не закреплены.

## Taboos

- Не делать сетку подграфиков по топливам: топливо — это кривая.
