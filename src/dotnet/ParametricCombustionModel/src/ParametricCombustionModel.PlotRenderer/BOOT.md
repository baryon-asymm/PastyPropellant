# BOOT.md — ParametricCombustionModel.PlotRenderer

## Purpose

Отрисовка графиков скорости горения по результату оптимизации: посчитанные
кривые, измеренные точки с доверительными интервалами, линейные и двойные
логарифмические оси. Сборка — библиотека; файлы она пишет в рабочий каталог
процесса.

## Invariants

- **Одно топливо — одна кривая.** Раскладка «по одному подграфику на топливо»
  в этом дереве запрещена: число топлив меняется от набора к набору, и сетка
  подграфиков рассыпается. Сетка, если нужна, строится по характеристикам или
  фазам, а топливо остаётся кривой.
- Ошибка рисования обязана доходить до вызывающей стороны исключением. OxyPlot
  по умолчанию превращает её в картинку с панелью ошибки, и этот узел эту
  подмену отменяет.
- Сборка ссылается на [Optimization](../ParametricCombustionModel.Optimization/API.md)
  напрямую. Раньше та же зависимость приходила транзитом через отчётность, ни
  одного типа которой узел не использовал; теперь она объявлена там, где ей
  место.
- Графики рассчитаны на печать: размеры и dpi по умолчанию заданы под
  вставку в PDF.

## Dependencies

- [Optimization](../ParametricCombustionModel.Optimization/API.md) — результат,
  по которому рисуются кривые;
- [Core](../ParametricCombustionModel.Core/API.md) — описание топлива, откуда
  берутся доверительные интервалы измерений.

Вне дерева: OxyPlot 2.2.0 и SkiaSharp 3.119.1 с нативными сборками для Linux.
