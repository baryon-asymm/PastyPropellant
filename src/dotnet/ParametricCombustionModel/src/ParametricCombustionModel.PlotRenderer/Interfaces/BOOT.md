# BOOT.md — Interfaces

## Purpose

Контракты рисовальщика: общий (сохранить модель графика в файл, байты или
поток) и два специализированных — по групповому результату и по результату
одной композиции.

## Invariants

- Общий контракт `IPlotRenderer` отвечает только за **вывод готовой модели**
  графика; он ничего не знает о результатах оптимизации.
- Специализированные контракты добавляют по одному методу `Render`,
  принимающему результат. Разделение неслучайно: только так вывод изображения
  можно переиспользовать между разными источниками данных.
- ⚠ `ISingleResultPlotRenderer` **никем не реализован** в дереве: все
  имеющиеся рисовальщики групповые. Контракт объявлен на будущее.
