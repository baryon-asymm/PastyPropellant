# BOOT.md — PropellantComponents

## Purpose

Рецептура топлива по компонентам: массовая доля и плотность каждого, плюс то,
что специфично именно для этого компонента — гранулометрия окислителя и
измеренная агломерация металла. Уровень существует, чтобы состав читался
типизированно, а не как словарь строк.

## Invariants

- `BaseComponent` — общий корень: массовая доля и плотность есть у всех четырёх
  компонентов и нигде не переопределяются.
- Компонентов ровно четыре, и это закрытое множество: разборщик в
  [Models](../API.md) сопоставляет имя JSON-свойства с именем типа через
  `nameof`, поэтому пятый компонент требует правки разборщика, а не только
  добавления записи.
- `AmmoniumPerchlorate.SmallParticlesFraction` — вычисляемое дополнение
  `1 − LargeParticlesFraction`, а не отдельное поле файла: сумма двух фракций
  тождественно единица и разойтись не может.
- `Aluminum.AgglomerationCoefficients` — 22 коэффициента полиномиальной
  аппроксимации `Z_a^m(p)`, байт-в-байт те же числа, что и
  `pocket_surface_fraction_coefficients` на верхнем уровне записи топлива.
  ⚠ Дублирование настоящее: две копии обязаны меняться вместе.
- `Aluminum.AgglomerationConfidenceIntervals` необязателен и по умолчанию
  `null`; давление в нём — **МПа**, а `size_of_confidence_interval` — полная
  высота уса, то есть ус достаёт до `y ± size/2`.

## Dependencies

- [Models](../API.md) — `ConfidenceInterval`, тип из родительского узла;
  `Aluminum` объявляет им свои доверительные интервалы.

## Constraints

Унаследованы от [Core](../../BOOT.md). Дополнительно: единицы задаются файлом
данных — плотность кг/м³, диаметр частиц м, доли безразмерны, а давление в
доверительных интервалах МПа. Записи единиц не знают.

- [x] `PropellantParsingTest.ParsePropellant` разбирает все четыре компонента
      реального файла (2026-09-05, `ParametricCombustionModel.Core.Tests`).
- [x] Каждое топливо несёт четыре измеренные точки `Z_a^m`, давления лежат в
      измеренном окне, усы не выходят за физический диапазон, и полином
      согласуется с измерениями

      [Computation.Tests](../../../../tests/ParametricCombustionModel.Computation.Tests/BOOT.md)).

      соглашение, которое держится вручную.

## Taboos

- Не расширять множество компонентов, не тронув разборщик в [Models](../API.md):
  неизвестное имя свойства там бросает `JsonException`.
- Не переводить `SmallParticlesFraction` в поле файла: инвариант суммы держится
  именно тем, что поля нет.
