# BOOT.md — GasPhases

## Purpose

Термодинамическое состояние газовой фазы над поверхностью горения — в том виде,
в каком оно приходит из внешнего термодинамического расчёта и лежит в
`data/propellants*.json`. Уровень существует, чтобы разделить два физически
разных случая: гомогенное пламя (одна температура) и гетерогенный карман, где
диффузионное пламя сосуществует с двумя кинетическими.

## Invariants

- Это данные, а не модель: ни одного вычисления, ни одной формулы. Значения
  посчитаны снаружи и только читаются.
- Единицы фиксированы файлом: `lambda_gas` — Вт/(м·К), `average_molar_mass` —
  кг/моль, `c_volume` — Дж/(кг·К), температуры — К. Записи безразмерны, единицу
  знает только потребитель.
- Каждое поле помечено `[JsonRequired]`: неполный газофазный блок — ошибка
  разбора, а не молчаливый ноль.
- `HeterogeneousGasPhase` содержит два `HomogeneousGasPhase` — каркасный и
  внекаркасный. Это единственное отношение между записями уровня.

## Dependencies

None.

## Constraints

`data/`, а не только код.
