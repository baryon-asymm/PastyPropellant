# BOOT.md — ParametricCombustionModel.Core

## Purpose

Сборка входных данных модели: типизированное описание топлива и его газовых
фаз, разбираемое из `data/propellants*.json`. Существует, чтобы все остальные
сборки дерева читали один и тот же контракт данных и ни одна не разбирала файл
сама.

## Invariants

- **Ни одной ссылки.** `ParametricCombustionModel.Core.csproj` не имеет ни
  `ProjectReference`, ни `PackageReference` — только базовая библиотека. Это и
  делает сборку безопасным дном дерева: она не может потянуть за собой ни
  UnitsNet, ни оптимизатор.
- В сборке нет ни одного вычисления: только записи, атрибуты сериализации и один
  разборщик компонентов.
- Ни одной единицы измерения в типах: числа безразмерны, единицу задаёт файл
  данных и знает потребитель. Это осознанное отличие от `Computation`, где
  величины идут через UnitsNet.
- Все типы — `record` (кроме разборщика), то есть сравниваются по значению и
  безопасны для параллельного чтения из нескольких воркеров.

## Dependencies

None.
