# BOOT.md — ParametricCombustionModel.Telemetry.Tests

## Purpose

Четыре проверки накапливающего измерителя кадров: кадр меряется, среднее
растёт, счётчик вызовов растёт, среднеквадратичное отклонение растёт.

## Invariants

- Все четыре проверки основаны на `Thread.Sleep(100)` / `Thread.Sleep(200)`
  и утверждают только **знак** («больше нуля», «больше прежнего»), не
  величину. Это сознательно: время сна не гарантировано, и любая проверка
  величины была бы хрупкой.
- ⚠ Обратная сторона: проверки почти не различают правильную реализацию от
  неправильной. Формула Уэлфорда, порядок обновления среднего и дисперсии,
  начальные `MinExecutionTime`/`MaxExecutionTime` и закрытие кадра через
  `Dispose()` не покрыты ничем.
- Каждая проверка занимает не меньше 100–300 мс реального времени: узел
  медленный по построению, четыре теста — около 0,9 с.
- Проект ссылается ещё и на `Core`, хотя ни один тест его типов не
  использует.

## Dependencies

- [Telemetry](../../src/ParametricCombustionModel.Telemetry/API.md) —
  проверяемая сборка.

Вне дерева: xunit.

## Constraints

Проект входит в `PastyPropellant.sln` и исполняется обычным `dotnet test`.
