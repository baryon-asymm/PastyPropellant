The (T_s + T_m)/2 rule at T_m = 2300 K puts T_pore at 1450..1600 K. The equilibrium carbon
curve there is SATURATED: 0.94..0.98 of the inventory is condensed for Bas_2 and Bas_4, so
the closure has no discrimination left and returns nearly the same number whatever happens.
That, not the closure itself, is what run M's 1.6..4.3x overshoot was. Inverting
f_s(T_pore,p) = measured over all 50 points (docs/results/required_pore_temperature.md):

    (T_s + 1300)/2                17 / 50
